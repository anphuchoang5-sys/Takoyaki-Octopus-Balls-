# 樱桃小丸子人物静态样板建模提示词

请开始制作《小丸子小镇》的首个角色：樱桃小丸子。

本次交付是可旋转、缩放查看的真实三维静态人物样板。我确认长相和身体比例后，你再制作走路、跑步动画；本次不要提前进入动作阶段。

## 参考与风格

- 主参考使用官方角色形象及同一版本的动画截图：`https://chibimaru.tv/about/chara/`。整理正面、侧面、背面参考；没有确切参考的背面或立体厚度，标明合理补全，不冒充官方设定。
- 首版采用白色上衣、红色背带裙的常见造型，按同一套参考统一领口、裙型、鞋袜和颜色；先不添加帽子、书包或换装。
- 场景风格对照现有樱家和 AME MART：清晰色块、柔和明暗、适度描边。保持小丸子的动画简洁感，不做写实皮肤、毛发或强烈塑料高光。
- 重点还原短发轮廓、锯齿状刘海、脸型、五官位置、头身比例和四肢粗细。先把轮廓与比例做好，再完善局部。
- 正面、四分之三侧面、纯侧面和背面都要成立；尤其重视第三视角常看到的后脑、发尾、肩背和裙子轮廓。不得用始终朝向相机的平面人物代替三维模型。

## 模型与比例

制作完整头部、躯干、四肢、衣服及鞋袜，采用自然站姿，双臂略微离开身体，便于检查轮廓。

模型为后续动作保留合理的肩、肘、髋、膝关节位置；静态样板阶段无需完成骨骼或动画。面部可以使用符合动画风格的简洁画法，但旋转时五官位置不能漂移或明显变形。

在独立对照场景中，把人物放到现有樱家门口、便利店旁，以及樱家室内门框或家具旁检查比例，不改这些资产的源文件。

室外是微缩街区，室内是进门后切换的独立空间：两边可使用各自的整体展示倍率，但人物自身头身比例保持一致，不通过拉伸头部或四肢强行适配建筑。说明推荐身高和倍率，脚底中心作为放置原点；尺寸属于项目设计，不宣称为官方实测。

## 独立预览

- 支持鼠标环绕、滚轮缩放、平移和一键回到全身。
- 提供正面、侧面、背面及面部近景快捷视角。
- 提供简洁背景与建筑比例对照，方便判断人物是否融入当前小镇。
- 展示真实模型；截图不能代替可操作的三维预览。
