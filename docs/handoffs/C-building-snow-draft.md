## 接口与唯一所有权

- 宿主调用 `asset.setEnvironment({time,weather,snowAmount})`，snowAmount 为 0～1；由全镇累计时间驱动，各处同步。建筑不能自己计时、开 RAF、保存雪量或按天气直接清空雪。
- 下雪 0→1 为 60 秒；晴天 1→0 为 300 秒；下雨 1→0 为 60 秒。中途保留残量，昼夜同速，后台及关闭期间暂停。
- 一个建筑地块内的屋顶/雨棚/围墙/庭院/小物由建筑生成；地图仅生成空地及道路雪，不在建筑格子上叠加白色底板。
- 当前适配提供 `asset.snow.sample(localX,localZ)` → `null` 或 `{y,normal:THREE.Vector3,name}`。它查询当前可见雪体顶面，供统一降水使用；坐标相对返回的 root，宿主完整转换世界矩阵。也支持第三参数 amount，仅供相邻地图地面衔接查询。
- 雪组标记 `userData.snowLayer=true`，原始屋顶几何索引会排除此动态组，避免把某一雪量永久缓存。若替换工具，保留这个标记与动态采样契约，或与 C 协调新的动态表面接口。
- `dispose()` 释放本实例拥有的雪几何和材质；不得释放其他实例、共享便利店资源或宿主灯池。
- `getLightingDescriptors` 的 position/target 均为 root 局部坐标；不载入独立预览灯光适配器。C 已接通 night-10 新描述优先。
