# みつや小店：动漫画面参考与建模清单

核验日期：2026-10-17。目标：整理一个以《樱桃小丸子》动画画面为主的小零食／杂物店参考清单。下方有 3 张参考图、22 类可制作部件和制作顺序；其中 A、B 是动画画面，C 是原作漫画门脸。部件可以组合为建模方案，但组合后的完整布局属于设计建议，不宣称是已考证的みつや全店平面。

## 已核验的来源

## 使用顺序与尚缺证据

1. 先以官方动画店内图确定色彩和可见道具。
2. ABEMA 图仅补充同作品零食陈列语言，等店名核实后再决定是否纳入みつや室内。
3. 原漫画门口图补门脸与空间关系，并明确标作漫画版本。
4. genpopo 完整门脸图留作追溯线索；找到对应片头帧或官方画稿出处后再升级。

目前未取得已核实的全店平面图、背面、侧面、屋顶尺寸、店内全景或同一版本的多机位连续画面。建模比例与被遮挡结构需要作为创作推定记录，不写成官方设定。本次仅在内存查看远程图片，没有下载图片或视频文件。

## 建议的第一版制作顺序

以下是制作建议，不是动画原设定：

1. **先搭门脸。** 前墙、门洞、屋顶、招牌和门帘先形成小店轮廓，保持入口可见。
2. **搭门口能看见的室内。** 斜面展示柜、窄长桌、三张圆凳和前景糖果罐优先，先复现 A 的可见关系。
3. **补店外识别物。** 冰旗、冰柜与竹帘按 C 补结构；未见细节先保持简单，并记录为推定。
4. **最后铺小杂物。** 用少量罐、盒、袋的基础形反复组合，再加商品卡、口味单和餐具。B 主要提供陈列方式与密度参考。

若先做一个可审看的局部，优先制作：门洞与木墙、招牌、门帘、斜面展示柜、糖果罐、窄桌和圆凳。其余结构可以在选定外观版本后再扩展。

## 动画风格控制建议

- **轮廓与色块优先。** 木柜和墙板用大块黄褐色、少量板缝表达；避免让细密木纹盖过手绘场景的简洁感。
- **保留玻璃里的内容物。** 糖果罐透明度和反光以看清糖果为目标，不追求摄影式强反射。
- **小物有规律地重复。** 用同形异色的糖果罐、盒装商品和圆凳形成层次。
- **颜色按选定动画图统一。** A 可见木褐、玻璃蓝、红蓝凳面、灰紫地面。C 是黑白漫画，不能提供屋顶、外墙或冰柜的动画配色。
- **先用门洞作比例基准。** 当前没有官方尺寸；具体米数、店铺纵深和不可见部分都属于建模时的设计决定。
