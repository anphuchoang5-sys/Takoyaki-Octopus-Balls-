## 技术细节与后续参考（已落地项见当前交接）

这些优先由制作窗口查代码、提出具体方案；只有影响用户体验或任务范围的取舍才需用户决定。

- 通用与专属按部位替换接口已落地，见当前交接；实际专属美术交付后的逐部位审看仍需进行。
- 共用环境计算放在何处、怎样兼容樱家自身色阶与其他建筑真实受光；方法职责已定，不要求新建复杂系统。
- 通用灯光描述的最小必填字段、点光／聚光的差异与默认参数。みつや现有字段可作为事实起点，但不是所有建筑已遵循的完整新标准。
- 季节字段／枚举、能力覆盖表是否需要机器可读数据。现在先用交付表说明，不提前强制所有资产增加字段。
- 三栋旧接口的兼容方式、未知字段／非法值的统一反馈、全镇状态失败后的恢复办法。不能通过静默丢弃已选择的环境来伪装支持。
- 环境保存的存储位置、导出结构／版本、布局与环境的一致性校验；保留原稳定 ID 和旧布局兼容。
- 多建筑超出灯池后的远处表现、阴影参数及性能指标；不自行扩大已有限额，不承诺无限真实灯。
