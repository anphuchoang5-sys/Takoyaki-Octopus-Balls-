# 小镇环境术语

本表只定义讨论用词。通用规则见[总览](README.md)，接口见[环境约定](environment-contract.md)。

## 环境

**时段**：早晨、下午、黄昏、夜晚所代表的光照与生活时刻。
避免把“四时段”说成“四季”或“四份建筑模型”。

**天气**：当前的晴天、降雨或降雪等气象条件，与时段和季节独立。

**季节状态**：建筑与庭院的季节装饰、陈设等表现。冬季状态不等于正在下雪。

**积雪量**：已经留下的雪的程度。它与当前是否下雪是两回事。

**共用规则**：多栋建筑共同采用的环境响应方式，例如室外夜灯在黄昏开启。

**建筑例外**：经过确认、区别于共用规则的局部安排，例如某店营业灯白天也亮。

**沿用表现**：明确决定在某个条件下使用已有表现，不要求另做一套美术。
避免用“沿用”掩盖尚未制作或未作决定的内容。

## 灯光与交付

**夜灯**：按黄昏、夜晚使用的灯光；不包括所有营业灯、设备指示灯。

**营业灯**：店内照明、冷柜和售货机等营业相关灯光，可以在日间保留。

**灯光描述**：建筑对当前所需照明的说明，不等于地图中已经存在的实际光源。

**独立预览**：单独查看建筑及其环境响应的场景，不代表正式地图已经接入。

**制作完成**：约定内容已制作并交付，不自动包含技术通过或用户画面认可。

**技术检查通过**：指定检查实际执行并通过，只覆盖相应检查范围。

**正式接入**：内容已在正式地图中连接并产生预期响应。

**用户画面认可**：用户明确接受某个版本和范围的画面，不自动延伸到别的版本、全镇组合或功能。
