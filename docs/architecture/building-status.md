## 樱家：沿用四时段，补接入

- [environment.js](../../dist/town/assets/sakura-house/environment.js) 已根据时段改变色调，黄昏／夜晚亮窗和显示路灯，黄昏光束／光斑弱于夜晚。`getEnvironmentState()` 用于读取现状。
- [geometry.js](../../dist/town/assets/sakura-house/geometry.js) 使用固定动画色阶材质；不能仅降低全镇太阳就期待它自动获得合适夜色。接入时保留自身响应，与其他建筑协调，不重复整栋染色。
- 当前天气白名单不接受 `snow`，直传会报错；`hail/wind/leaves` 即使可接收，也没有对应完整视觉。需要明确适配，不能把雪请求静默伪装成晴天并称已完成。
- 补齐屋顶、雨棚、围墙、院地、植物等适合其形状的积雪；原檐口滴水与地图雨各自一套，不重复生成。
- 依据：[工厂](../../dist/town/assets/sakura-house/index.js)、[建筑交接](../handoffs/B-sakura-house.md)、[屋顶 04 记录](../actions/2026-10-20-B-sakura-roof.md)。双圆光晕重做、室内家具精修不属于本接口接入。

## みつや：沿用 night-10，更新宿主消费方式

- [environment.js](../../dist/town/assets/mitsuya/environment.js) 已提供 `setEnvironment()`、`getEnvironment()`、`getLightingDescriptors()`；早晨与下午相同，黄昏使用 45% 的夜景过渡。这个 45% 是现有本店实现，不是已确定的全镇统一系数。
- 日间两灯都开着；黄昏增强，夜晚使用各自夜间强度、距离和向入口的目标。需要编辑器同时转换 position 与 target，旧固定向下目标无法完整表达新夜景。
- 当前接受 `snow` 等天气，但只记录状态，明确报告 `snowImplemented:false`、`weatherEffectsImplemented:false`。仍需实际制作积雪，不能把该接口当成雪景资产。

- [夜晚交付记录](../actions/2026-10-20-B-mitsuya-night.md)正文保留制作时的历史状态，顶部补记后续用户已认可建筑夜景。地图中的曝光、可见度和灯池覆盖仍需实际审看。
