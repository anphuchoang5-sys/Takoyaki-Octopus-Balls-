# 可拼接街区与第三人称散步

## Status and situation
本地实现及浏览器检查已完成，待执行既有授权的私有发布；发布终态单独保存在 artifacts/walk/deployment.json。用户明确目标为多个方形建筑地块按地图点位放置，统一时间与天气；确认第三人称，并请求可走动人物。已有雨夜便利店演示保留为独立观赏页。
已确认：时间分为早晨、下午、黄昏、夜晚；天气分为晴、雨、冰雹，两组可组合。建筑保持同一三维结构，通过环境响应改变表现，避免多个互不一致的模型副本。人物先采用原创日系卡通旅人。现有私有 Sites 的源码上传及发布授权继续适用。
本轮目标：可行走的 3×3 地块街区原型、至少四种地块、角色动作、相机跟随与遮挡处理、碰撞、统一时间天气与地块放置记录。不包含地图编辑器、角色换装或完整商店经营。

## Implementation measures
1. 以独立 /walk/ 页面增加第三人称原型，保留已有展示页。
2. 建立地块目录与放置配置，统一尺寸、原点、朝向、道路标高和建筑碰撞。
3. 制作原创角色模型及待机、走路、跑步动作；控制移动、跟随相机、视角遮挡。
4. 集中管理太阳、天空、照明、降雨/冰雹与湿润度，建筑只保留灯具、玻璃、屋檐等局部响应。
5. 用真实浏览器验证移动、碰撞、地块组合、状态组合及渲染；生成单文件并更新既有私有发布。

## Affected file tree
- dist/walk/index.html：无游戏界面覆盖的第三人称入口。
- dist/walk/main.js：运行循环、输入与场景组合。
- dist/walk/character.js：原创旅人模型与关节动画。
- dist/walk/buildings.js：可复用地块模型及碰撞/灯具描述。
- dist/walk/environment.js：统一时间、天气、地面湿润与降水效果。
- dist/walk/map.js：地图点位放置与空间查询。
- scripts/inspect-walk.mjs：散步原型浏览器检查。
- scripts/inspect-walk-states.mjs：走跑速度、感应门及全部时间天气组合检查。
- dist/world.js：静态合批支持指定根节点，并区分有索引与无索引几何。
- scripts/serve.mjs：支持 /walk/ 子目录入口。
- scripts/standalone.mjs：兼容新增页面的离线打包。
- README.md：两种观看方式与控制说明。
- artifacts/（忽略提交）：检查截图、结果、离线版与部署记录。

## Self-verification method
JavaScript 语法；浏览器控制台；角色真实移动和碰撞；时间与天气组合；截图核对九块地面衔接、角色清晰度及昼夜气氛；打包后 file 协议实际打开；原生私有部署终态。

- 原型实际渲染与操作通过：九个唯一地图点位、五类建筑、同一环境实例；人物移动与建筑墙面阻挡通过，浏览器控制台无错误。

- `scripts/inspect-walk-states.mjs` 通过：跑步实际移动速度约为散步的 1.69 倍，松开后恢复待机；靠近便利店时门开度为 0.9996；4 个时段 × 3 种天气全部通过。晴天过渡后雨量与冰雹量均小于 0.001。结果在 `artifacts/walk/states-inspection.json`。
