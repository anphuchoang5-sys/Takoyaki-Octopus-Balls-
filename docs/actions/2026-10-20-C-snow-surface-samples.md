## 实际结果

### 已执行

- 6 个新增 JS 与检查 MJS 执行 `node --check`，全部退出 0；证据 `artifacts/editor/snow-surface-samples/syntax.json`。
- `node scripts/inspect-snow-surface-samples.mjs`：实际 Chrome、独立 context、现有 4173 服务。45 项中 44 项当次通过；唯一失败是屋顶满雪的底面抽样数为 0，原 `inspection.json` 保留。
- 定向补测：原步长每次恰好落在屋顶顶面，没有抽到任何底面。改成非同相位遍历，误差门槛仍为 `1e-4`，没有为检查改几何；稀疏/满雪各 35 个底面与原模型独立射线高度差分别不超过 `8.994e-8` / `1.214e-7`。`contact-followup.json` 两项均通过，补齐唯一未覆盖项。
- 覆盖/厚度：6 个雪量阶段；覆盖逐渐增加，薄雪接近全覆盖后继续加厚。雪体底部与真实表面接触、侧壁向外。渲染网格独立射线与雪面查询匹配，稀疏雪孔隙不返回隐藏雪面。
- 实际操作：左键旋转、滚轮缩放、滑杆更新、连续演示/暂停、归零、非法雪量拒绝、刷新隔离。原模型几何/颜色指纹未变；独立实例释放只发生一次，不影响其他实例；重复雪量更新 GPU 几何计数未增长。
- 隔离：127 个既有 `dist` 文件 SHA-256 与开始时全部一致；Storage API 调用 0、页面错误 0。本轮没有启动正式地图页面，没有改用户布局或保存键。
- 12 张同镜头阶段截图、3 张低角度截图、同场截图；文件目录和操作见[交接](../handoffs/C-snow-surface-samples.md)。
- `node scripts/inspect-snow-surface-samples.mjs --record`：原录制入口因本机缺 Playwright ffmpeg 失败，未安装依赖；改用 Chrome 原生 MediaRecorder，录下三个真实场景各 15 秒的完整渐进过程。`continuous-accumulation.webm` 约 12.8 MB，`continuous-timeline.json` 记录请求雪量和实际显示雪量。视频叠加的百分比来自已显示网格，不是另画动画。实际解码抽查 8/25/43 秒，均为 1440×1000、readyState 4，见 `video-validation.json` 与抽帧图。
- 本机观察：三个小样同场静止时 49 个 draw call、约 26.3 万绘制三角形、49 个 GPU 几何/3 张纹理；无界面 Chrome 的 RAF 中位间隔约 6.9 ms、P95 约 7.1 ms。连续录制中该间隔相近。这只说明本机小样主线程观察，不能声称全镇/移动端性能已通过。
- 满雪屋顶后台几何更新约 0.5 秒，拖动会稍后跟随；没有用静止帧率掩盖生成开销。初次屋顶准备约 2～3 秒。正式推广前仍需性能优化。

### 中途修正与限制

初版逐小面挤出导致硬边/细缝，已在本试验内改为精确遮挡裁切、连接补齐与厚雪顶面平滑。一次遮挡裁切运算因不相交多边形也被拆分而超时，修正后预览可正常载入。首次完整检查在刷新后引用尚未创建的全局变量时报错，修正为 `window.snowSamples` 后完成检查；与模型错误分开记录。

灌木最终采用みつや现有右侧三叶团；叶片标记原样保留，不将每个细小标记拉成长雪柱。屋顶/路面来自真实几何；路面的沥青本身没有细粒几何。厚度、雪斑大小、边缘软硬和浅蓝明暗均为本轮待认可效果，近景可见原低面数植物轮廓。
