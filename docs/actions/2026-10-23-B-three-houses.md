# 三栋参考住宅外观制作

## Status and situation

Completed（外观制作、本轮定向技术检查与本地交付完成，画面待用户认可）。用户授权按所附三张图依次制作小玉家、爷爷奶奶家、小衫家。本轮为实际三维外观、可旋转缩放预览、参考对照、交换模型和定向验证；不接入地图、不制作独立室内、专属雪或全镇灯光。

已完整读取项目 AGENTS、project-control-report、action-document、环境约定与当前交接。开始时 Git 存在厨房、前田家及编辑器雪缓冲等未提交修改；全部保留。不使用子代理，不启停服务、不做整项目回归、不提交推送发布或清理。

三张参考主要为正面，侧后方、纵深和米制尺寸均为补全，不能称严格复原。尚无已确认占地，本轮分别按可见比例设置独立预览地块，不声称已有多格编辑器支持。当前 catalog 未引用三栋新资产，新增源码不改变首页。

## Implementation measures

1. 保存用户原始参考；按各图轮廓、配色、屋面连接、门窗与庭院分别建立独立资产文件夹。
2. 复用现有 flowerorangebuilding/geometry.js 的按实例几何工具；新增仅供这批住宅使用的共用门窗、板墙、屋面与植物辅助，不修改既有资产或雪代码。
3. 先体量、屋面和门窗，再围墙、植物和局部细节；屋檐、框体、栏杆、瓦缝/板缝有实际厚度，玻璃用动画蓝色材质。
4. 预览包含参考机位、正面、两侧、背面、俯视及重点近景；提供原图同屏、植物显隐和真实鼠标操作。新资产无旧版，参考对照不冒充修改前后。
5. 隔离浏览器读取本地文件，检查有限几何、包围盒、屋面连贯与开口、实例资源、交互、GLB 回读和离线预览；实际查看截图再调整。

### 发现与修正

1. 沙箱内 Chrome 首次 `spawn EPERM`，没有产生有效浏览器检查；随后用获准的隔离本机 Chrome 完成本轮检查。脚本在浏览器内拦截本地文件请求，未启动服务，也不写 localStorage。
2. 首轮发现小玉家门扇向街道外打开和部分树冠越出地块；改为向院内半开、调整树冠尺寸与位置，最终边界通过。
3. 首轮实际截图发现小玉家侧封板按对称山墙错误穿出不对称后屋面，以及侧窗与墙洞错位；按真实坡面补板并对齐开口，新增屋面射线检查防止复发。
4. 爷爷奶奶家右山墙原先与长屋脊齐高，未对应参考轮廓；抬高前山墙并以匹配交线回接长坡，玄关、院门和通道对齐。
5. 小衫家高屋板缝改为顺坡方向，补齐高低体块连接侧墙；另外两栋凸出房间也补齐回接侧墙和檐下封板，避免只从正面看成立。
6. 调整全景相机防止裁切；调整花木冠形，并收开植物与墙、屋檐的间距；窗、栏杆、雨棚、门柱均为实体构件，玻璃为动画蓝色，未靠图片代替三维。
