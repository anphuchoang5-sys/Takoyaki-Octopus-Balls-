### 6 / 12 栋同协议实测

运行 `node scripts/diagnose-snow-memory.mjs --bench --count=N --label=final-before/after-N --limit=1800 --frame-ms=6000 --dynamic --out=artifacts/editor/shadow-update`；before 追加 `--source-dir=artifacts/editor/shadow-update/before-source`，只替换本轮 main/lighting 源码，不回退工作区。6/12 栋是樱家、便利店、みつや各 2/4 个实例，非 6/12 种建筑。Chrome 独立 profile，1280×800、DPR1、RTX 4060 Laptop D3D11；每段至少 180 帧和 6 秒，无 Profiler/强制 GC。汇总及源码摘要：`artifacts/editor/shadow-update/comparison.json`。

| 指标 | 6 栋优化前 → 后 | 12 栋优化前 → 后 |
| --- | --- | --- |
| 晴天下午 FPS | 25.8 → 39.8 | 14.1 → 20.8 |
| 厚雪下午 FPS | 20.4 → 26.5 | 10.3 → 13.5 |
| 厚雪夜晚 FPS | 19.0 → 26.2 | 10.1 → 13.5 |
| 厚雪夜晚 P95 帧间隔（ms，越低越好） | 60.2 → 45.9 | 108.7 → 79.8 |
| 持续积雪 FPS | 17.8 → 25.6 | 9.5 → 12.6 |
| 下雨融雪 FPS | 21.1 → 32.8 | 两侧均未运行到此阶段 |
| 厚雪夜晚每帧绘制提交 | 5392 → 1721（-68%） | 9371 → 3425（-63%） |
| 采样最高私有提交量（MiB） | 1508 → 1463 | 1945 → 1902，均保护停止 |
| 首次满雪准备（秒） | 7.16 → 6.87 | 7.44 → 7.39 |

内存是本次隔离 Chrome 各进程（含 GPU 进程）私有提交量总和，既非物理 RAM、专用显存，也非“雪独占”；仅阶段采样，不是连续峰值。稳定厚雪夜晚约为 1287 → 1295 / 1717 → 1685 MiB；不能宣称内存大幅下降。旧/新 12 栋均在动态积雪后的采样超过既有 1900 MiB 保护线，脚本主动停止并关闭自己的浏览器，未出现 PAGE_CRASH，但压力检查未通过。12 栋雨中融雪及正常清雪收尾因此没有本轮完整证据。此前候选 `after-12` 也在 1916 MiB 停止，保留失败记录，没有调高保护阈值制造通过。

6 栋完成全部阶段，清雪后 Worker/来源/帧缓存归零，最终总量 1401 → 1230 MiB；不把浏览器分配器的回收时机当成精确节省量。动态生成仍需要工作缓冲；现有建筑和雪面仍有大量普通绘制。本轮主要消除了不变阴影的重复深度绘制，**12 栋仍未达到轻量、流畅目标**，不能外推为大量建筑压力已解决。未验证 100 栋、低端 GPU、手机或数小时连续运行。
