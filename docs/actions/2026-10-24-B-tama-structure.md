### 发现和修正

1. 沙箱 Chrome 首次启动 `spawn EPERM`，这次未产生视觉验证；改用获准的隔离无界面 Chrome，通过浏览器路由读本地文件，不启动服务，不访问编辑器/存档。
2. 首轮真实截图发现树冠仍像堆球、侧窗受挡、山墙细白边被曲线拉弯及院墙端面闪烁；换连续起伏树冠并后移大树，白边按直坡连接，院墙端部内芯退让。草叶由圆柱改为带厚度的小叶片几何，保留草地形状并减少无用面数。
3. 同机位验证曾因 JSON 把 -0 序列化为 0 导致深比较失败；这是比较方法误报，改为相同 JSON 表示比较，保留位置和投影所有数值，最终通过。
4. 用户途中指出院门还应偏左及围墙高低不齐；查实前墙 1.80、侧后墙 1.53，按追加要求统一高度、移门和灌木，并修正门柱侧面被院墙露出的粉色窄条；最终重新打包和运行以上检查。
