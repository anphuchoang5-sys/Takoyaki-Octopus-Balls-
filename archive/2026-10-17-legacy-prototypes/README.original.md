# 小丸子小镇

一个可以摆放建筑、选择时间与天气、切换视角散步探索的小镇项目。当前已有地图编辑器、旧散步原型和雨夜便利店观赏页；编辑器的人物及统一环境仍在接入规划中。

实际项目目录：`E:\动森\小丸子小镇`，实体目录已于 2026-10-17 完成改名。`E:\动森\rainy-corner` 和 `E:\动森\小丸子的小镇` 仅保留为兼容联接，三个路径访问同一份文件，没有项目副本。后续窗口使用实际目录；改名与代码排查见 `docs/actions/2026-10-17-project-rename-and-code-audit.md`。

## 小丸子小镇：第三人称散步原型

进入 `/walk/`，或双击 `artifacts/雨待町散步.html`。线上入口：https://ame-mart-rainy-corner.fengyycon.chatgpt.site/walk/ 。本地离线版可通过 `node scripts/standalone.mjs --walk` 重新生成。

| 操作 | 按键 |
| --- | --- |
| 散步 / 跑步 | WASD 或方向键 / 按住 Shift |
| 转动镜头 / 拉近拉远 | 鼠标拖动 / 滚轮 |
| 向左右转镜头 | Q / E |
| 回到起点 / 整张地图视角 | Home / V |
| 早晨 / 下午 / 黄昏 / 夜晚 | 1 / 2 / 3 / 4 |
| 晴天 / 下雨 / 冰雹 | C / R / H |

触屏左侧拖动移动、右侧拖动转镜头；尚未进行真实手机性能和触控验收。

目前有 3×3 地图、九个点位、五类地块：便利店、咖啡店、书店、住宅、小公园。原创旅人有待机呼吸、走路、跑步和转向，雨天与冰雹天会戴上兜帽。自动门随靠近开合，建筑与主要道具有碰撞；相机遇到建筑会拉近，避免墙体完全遮住人物。

时间与天气独立组合，共 12 种组合；全地图只运行一套环境。统一控制天空、日光、灯光、雨滴、冰雹、路面湿润反射与玻璃水痕，切换天气后地面逐渐变干。当前用按键切换时间，没有自动推进日历。

### 建筑地块约定

- `dist/town/assets/` 按一栋建筑一个文件夹保存模型：`convenience/` 便利店、`cafe/` 咖啡店、`bookshop/` 书店、`home/` 普通住宅、`garden/` 小公园。修改建筑直接打开对应文件夹；详细指引见该目录的 `README.md`。
- `dist/town/assets/index.js` 统一提供创建入口，旧 `dist/walk/buildings.js` 保留兼容转发。统一使用 14×14 单位正方形地块，原点在中心、默认正面朝 +Z。
- `dist/walk/map.js` 的 `PLACEMENTS` 保存每个实例的稳定 id、建筑类型、网格点位、90° 朝向和可选外观。地图根据这些记录复制、旋转并放置模型，拒绝重复点位。
- 每种建筑同时提供碰撞、相机遮挡、屋顶遮雨范围、灯具和地面高度。斜屋顶包含屋脊方向与高度，以便降水落在屋面上。
- `dist/walk/environment.js` 集中管理时间、天气与湿润度；建筑不持有独立天气时钟，不需要为每种天气复制整套模型。
- `dist/walk/character.js` 管理人物几何和动作；`dist/walk/main.js` 连接输入、相机与运行循环。

这是可游玩的基础原型，该页面的点位仍在配置中设置。独立地图编辑器已位于 `/editor-preview/`，提供便利店和四种道路的放置、旋转与保存；人物和统一环境尚未接入该编辑器。咖啡店、书店、住宅和小公园仍是旧样稿，不代表新一批原作建筑已经交付。尚无角色换装、NPC 或经营玩法。

开发检查：`node scripts/inspect-walk.mjs` 核对移动、碰撞和画面；`node scripts/inspect-walk-states.mjs` 核对走跑速度、自动门及 12 种环境组合。检查使用本机 Chrome 和 Playwright，结果保存于 `artifacts/walk/`。

## 原有雨夜便利店：观看

原有 `/` 页面仍为完整方形底座上的无人物观赏模型，商品、日文招牌与海报均为场景内部物件。

- 鼠标左键拖动：旋转；右键拖动：平移；滚轮：缩放。
- 触屏：单指旋转，双指缩放及平移。
- 聚焦画布后，方向键旋转，`+` / `-` 缩放，`Home` 回到完整构图。
- 窗口尺寸变化时自动调整构图；系统开启减少动态时，环境动画减速。

本地直接观看：双击 `artifacts/雨夜便利店.html`，全部依赖已内嵌，无需安装或启动服务。可使用 `node scripts/standalone.mjs` 从当前源码重新生成该文件。

开发预览：在此目录运行 `node scripts/serve.mjs`，打开 http://127.0.0.1:4173 。运行只需 Node.js，已内置的 Three.js 资源不需要重新下载。停止本地服务使用启动它的终端中的 Ctrl+C。浏览器须支持 WebGL 2。

## 内容

便利店有两面透明橱窗、滑动门、暖色照明、饮料冰柜、装满商品的货架、饭团、便当、咖啡机、关东煮、收银区、冰淇淋柜、杂志架和后场门。街角包含贩卖机、自行车、雨伞架、垃圾分类桶、路灯、电线杆及电线、交通信号灯、护栏、停车位、排水沟、斑马线、公告栏、后巷与空调外机。

环境包括持续降雨、屋檐滴水、扩散波纹、玻璃滑水、随视角变化的湿路反射、轻微灯光闪烁与交通灯循环。自动门每 22 秒开合一次。

## 文件职责

- `dist/scene.js`：页面入口、相机交互、照明、后期处理及动画循环。
- `dist/world.js`：几何工具、三渲二材质、文字贴图及静态模型合批。
- `dist/town/assets/convenience/store.js`：便利店建筑、店内陈设、招牌和自动门；`dist/store.js` 为旧入口兼容转发。
- `dist/street.js`：底座、道路、街角道具与交通灯。
- `dist/weather.js`：雨线、波纹、水痕与实时反射。
- `dist/vendor/`：固定版本 Three.js 0.180.0 及 MIT 许可文件。
- `scripts/inspect.mjs`：使用已安装 Chrome 的浏览器检查与截图；仅开发验证需要 Playwright。
- `docs/actions/2026-10-16-rainy-corner.md`：实现和检查记录。

渲染实现参考 [Three.js 官方文档](https://threejs.org/docs/)，运行依赖已固定在本地，未调用生成式 API。
