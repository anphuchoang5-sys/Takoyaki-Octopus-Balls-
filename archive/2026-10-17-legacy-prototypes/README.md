# 旧原型归档 · 2026-10-17

这里保留整理前的雨夜便利店观赏页和固定九地块散步原型。当前产品是主项目首页的小镇规划编辑器；本目录不在 `dist` 中，不随正式页面加载或发布。

## 本地打开归档

在本目录打开 PowerShell，使用独立端口，避免与主编辑器冲突：

```powershell
$env:PORT = '4190'
node scripts/serve.mjs
```

- `http://127.0.0.1:4190/`：原雨夜便利店观赏页。
- `http://127.0.0.1:4190/walk/`：原固定地图散步页。
- 结束查看后，在启动服务的终端按 Ctrl+C。

归档内 `dist` 已包含页面、完整 JS 依赖和 Three.js 许可；启动只需要 Node.js，不需要联网下载模型。原操作说明保存在 `README.original.md`。

`manifest.json` 记录 44 个原文件的路径、字节数和 SHA256，均为整理前逐字复制的快照。共用文件在这里保留的是历史版本，后续建筑维护只修改主项目的 `dist/town/assets/`。

`scripts/` 中的旧检查和离线打包脚本也按原样保存，属于历史工具；其中部分默认地址仍为 4173，不能直接当成当前正式编辑器检查执行。当前编辑器检查位于主项目 `scripts/inspect-editor.mjs`。

樱家是后续建筑窗口的新作品，保留在主项目 `dist/town/assets/sakura-house/`，没有归入此旧原型档案。归档页里旧旅人和旧环境的存在，也不表示它们已经接入当前编辑器。
